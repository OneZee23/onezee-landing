This site used to be a single landing page. Now it has a blog — and the posts
write themselves, sort of.

Here's the flow: when I publish something in my Telegram channel and tag it
`#site`, a small scheduled job reads the channel, turns that post into a static
page, and ships it here. No CMS, no copy-paste. The page you're reading is a real
pre-rendered HTML document, so search engines can actually index it.

This first post is a placeholder so the layout has something to show. Delete it
whenever — the next real one will arrive straight from Telegram.
